# سیاست امنیتی

اگر ایراد امنیتی در پنل آریو پیدا کردید، آن را در Issue عمومی ثبت نکنید.

گزارش را از زبانهٔ **Security** همین مخزن و مسیر «گزارش آسیب‌پذیری خصوصی» (Private vulnerability reporting) ارسال کنید. فقط نگهدارندگان مخزن آن را می‌بینند.

در گزارش، لینک اشتراک، اطلاعات پرداخت یا اطلاعات مشتریان را نفرستید، مگر برای بازتولید ایراد ضروری باشد؛ در آن صورت حداقل دادهٔ لازم را ذکر کنید.

# Security Policy

If you find a security vulnerability in Ario Panel, do not file a public issue.

Please report it privately from this repository's **Security** tab, using GitHub's private vulnerability reporting. Only the repository maintainers will see the report.

Do not include subscription links, payment details, or customer data unless they are strictly required to reproduce the issue, and then include only the minimum necessary.
